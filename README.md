# paseo-streamdeck

A Stream Deck plugin that shows live [Paseo](https://paseo.sh) agent status on a single key:

| Row | Color | Meaning |
| --- | --- | --- |
| ▶ | green | agents running |
| ! | amber / red | agents needing attention: questions/permissions, or errors |
| ✓ | blue | agents that finished and were not acknowledged yet |

**Press the key** to acknowledge finished/error agents (clears their attention flag in Paseo) and open or focus the Paseo desktop app.

When the daemon is unreachable the key shows `OFFLINE`; while reconnecting it shows `CONNECTING`.

## Install

1. Download `com.lucaslosi.paseo-status.streamDeckPlugin` from the [latest release](../../releases/latest).
2. Double-click it to install into the Stream Deck app.
3. Drag **Paseo Status** from the *Paseo* category onto a key.

Requires Stream Deck 6.5+ (the plugin runs on the bundled Node.js 20 runtime).

## Configuration

Select the key and use the property inspector:

| Setting | Default | Description |
| --- | --- | --- |
| Daemons | `ws://127.0.0.1:6767/ws` | One daemon per line: `url`, `label \| url`, or `label \| url \| password` |
| Paseo app | *(auto-detect)* | Path to the Paseo desktop executable |

Example — workstation plus homelab:

```
ws://127.0.0.1:6767/ws
Homelab | ws://192.168.0.138:6767/ws
```

## How it works

The plugin connects directly to every configured Paseo daemon over its WebSocket API using the
official `@getpaseo/client` SDK. Each connection loads the active agent directory once, then
follows live `agent_update` events, resyncing every 60 seconds and reconnecting automatically.
Counts are aggregated across all reachable daemons. A small amber dot in the bottom-left corner
means at least one configured daemon is unreachable.

Counts mirror Paseo's own state buckets:

- **needs attention** — `pendingPermissions` non-empty (tool/plan/question/mode requests) or `attentionReason: "permission"`
- **failed** — `status: "error"` or `attentionReason: "error"`
- **done** — `requiresAttention` with a `"finished"` reason
- **running** — `status: "running"` or `"initializing"`

Pressing the key calls `clearAgentAttention` for agents whose attention reason is `finished` or
`error` (pending questions are left untouched) on every reachable daemon, then brings the running
Paseo desktop app to the foreground. Paseo is launched only when it is not already running, so a
press never opens a second window.

> The `@getpaseo/client` version is pinned to the daemon version it was built against
> (currently `0.7.2`). Bump it in `package.json` when you update Paseo.

## Development

```bash
npm install
npm run link     # build + link into the Stream Deck app (developer mode)
npm run watch    # rebuild on change and restart the plugin
npm run validate # manifest/plugin validation
npm run pack     # produce com.lucaslosi.paseo-status.streamDeckPlugin
npm run preview:svg -- ./out  # write sample key images (SVG) for each state
```

Icons are generated by `scripts/generate-icons.ps1` (Windows-only; regenerated PNGs are committed).

### Layout

```
src/
  plugin.ts               entry point, settings wiring
  actions/status-key.ts   the key action (render, press)
  paseo/daemons.ts        daemon list parsing
  paseo/monitor.ts        multi-daemon connections, live agent directory, ack
  paseo/state.ts          status aggregation (counts)
  paseo/open.ts           focus / launch Paseo
  render/svg.ts           key image renderer (SVG data URI)
  settings.ts             global settings snapshot
```
